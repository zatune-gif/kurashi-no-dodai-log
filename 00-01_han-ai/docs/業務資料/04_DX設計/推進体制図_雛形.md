## 1. 体制図（テキスト版）

```
                 ┌─────────────────────────┐
                 │  経営者（ビジョンを描く人）  │  ← 投資判断・最終決定
                 └───────────┬─────────────┘
                             │
              ┌──────────────┴──────────────┐
              │  DX推進リーダー（橋渡し役）      │  ← 業務の目的定義・設計・調整
              │  社内：〔　〕／外部：ざつね屋     │
              └───┬───────────┬──────────┬───┘
         ┌────────┘           │          └────────┐
 ┌───────┴───────┐  ┌────────┴───────┐  ┌───────┴────────┐
 │ データを扱う人      │  │ 技術を実装する人   │  │ 現場で使いこなす人  │
 │ 社内：〔経理/管理〕 │  │ 社内 or 外注：〔　〕│  │ 各現場の担当：〔　〕│
 └───────────────┘  └────────────────┘  └────────────────┘
```

## 2. 役割と担当

| 役割 | 主な仕事 | 担当（社内） | 補完（外部/ざつね屋） |
|---|---|---|---|
| ビジョンを描く人 | 向かう先を決め、投資を判断する | 〔経営者〕 | ― |
| 橋渡しする人 | 業務の目的定義・変え方の設計・関係者調整 | 〔　〕 | ざつね屋 |
| データを扱う人 | データを集め、整え、読み解く | 〔　〕 | 〔　〕 |
| 技術を実装する人 | ツールを作る・つなぐ・運用する | 〔　〕 | 〔外注可〕 |
| 現場で使いこなす人 | 日々使い、改善点を返す | 〔各現場〕 | ― |

## 3. 会議体

| 会議 | 頻度 | 参加者 | そこで決めること |
|---|---|---|---|
| DX推進会議 | 〔月1回〕 | 経営者・推進リーダー・各役割 | 進捗確認、テーマの優先順位、投資の可否 |
| 現場ふりかえり | 〔隔週〕 | 推進リーダー・現場担当 | 使い勝手の問題、改善点 |

## 4. エスカレーション経路

- 現場で解決できない問題 → 推進リーダー → （投資・方針に関わるもの）経営者
- 判断の期限：〔例：推進会議を待たず、3営業日以内にリーダーが一次判断〕

## 5. 外部支援（ざつね屋）の範囲

- 範囲に含む：〔設計・進行・分析・現場伴走・研修〕
- 範囲に含まない：〔システムの構築・保守、データ入力の代行 等〕
