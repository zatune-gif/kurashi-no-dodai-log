# 記入例：せとうち園芸資材（仮）の伴走事例

このフォルダは、業務資料キットの各テンプレートを**架空の会社で記入したらどうなるか**の見本です。
実在の会社・案件ではありません。空欄テンプレートは各層フォルダの同名ファイルを使ってください。

---

## サンプル会社

| | |
|---|---|
| 会社名 | せとうち園芸資材（仮） |
| 事業 | 園芸・農業資材の卸売（プランター、培養土、支柱、防虫ネット 等） |
| 所在 | 広島県三原市（本社兼倉庫1拠点） |
| 従業員 | 24名（営業6／営業事務3／倉庫5／経理2／総務2／役員2／他4） |
| 売上 | 年商 約7億円 |
| 経営 | 2代目社長。週1で時間が取れ、数百万円規模の投資判断が可能 |

## 相談のきっかけ

- 春・秋の繁忙期に、営業事務の残業が月40時間超で常態化
- 受注が電話・FAX・メールでバラバラ。受注をシステムに入れた後、紙の控えにも書き写している（二重）
- 在庫確認が倉庫の1名の手作業で1日1回。受注から出荷まで平均3.5日
- 販売管理システムに10年分の受注データがあるが、月次売上を見る程度で活用できていない

## 見立てと進め方

初回ヒアリング・簡易診断の結果、**業務改善設計から入り、続けて受注〜出荷をBPRで再設計**する2段構え。
在庫最適化・需要予測（DX）は、在庫データが整ってからの将来テーマとして保留。

| 段階 | やること | このフォルダの記入例 |
|---|---|---|
| 入口 | ヒアリング・診断・提案・見積 | `01_入口/` の4ファイル |
| 第1段階：業務改善 | 受注事務の可視化 → ECRSで改善（紙控え廃止・出荷リスト自動化） | `02_業務改善設計/` の2ファイル |
| 第2段階：BPR | 受注〜出荷の原因分析 → 施策検討（A/B/C案）→ 移行計画 | `03_BPR設計/` の3ファイル |
| 第3段階：実行・検証 | 在庫のクラウド共有を立上げ、KPIで効果を測る | `05_共通運営_自走化/KPI定義_効果測定` `判断ログ` |
| 将来：DX | 在庫最適化・需要予測のテーマ整理 | `04_DX設計/` の2ファイル |

## この事例で見えること

- 「一番困っている人の作業（事務の残業）」と「一番詰まっている工程（在庫確認）」は別。数字で律速工程を特定している
- 改善は**投資ゼロの案（紙控え廃止・出荷リスト自動化）から着手**。効果を見せてから在庫共有へ
- KPIは目標未達でも「なぜ」を書いて次アクションにつなげている（リードタイム 3.5日→2.6日、目標1.5日は継続中）
- C案（在庫引当機能＋ハンディ）は保留し、DXテーマ判断とセットにしている
