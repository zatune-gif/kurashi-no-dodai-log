# ざつね屋 Webサイト下層ページ デザイン仕様

## 成果物

5系統・Desktop/Mobile各1枚、計10枚の自己完結SVGカンプをPNGへ変換しています。Desktopは1440×1800px、Mobileは390×1600pxです。各カンプは外部写真に依存せず、写真領域を「画像指示：顔が判別できない手元・後ろ姿」とした実装用プレースホルダーで表現しています。

## 共通デザインシステム

| 要素 | 指定 |
| --- | --- |
| 背景 | `#EFF4F5` と白 |
| 基調色 | `#5BBDC8`（青緑）、濃ティール `#173F46` |
| CTA | `#F8981D`（オレンジ） |
| 見出し | Noto Serif JP / Shippori Mincho 系の明朝体 |
| 本文 | Noto Sans JP 系。本文16px相当以上、読みやすい行間 |
| 余白 | 4pxグリッド。Desktopは大きな章間余白、Mobileは16〜24pxの左右余白 |
| 造形 | 低不透明度の水彩風ブロブ、波形、2px程度のモノライン図形 |

主CTAは「AI活用診断（無料）」で `https://han-ai-diagnosis.netlify.app/`、補助CTAは「無料相談・お問い合わせ」です。共通フッター表記は `© 2026 ざつね屋` です。

## ページ別構成

### 1. サービス一覧（services）

1. ヒーロー：「『使える』まで、一緒に整える。」、主・補助CTA、人物写真の選定指示。
2. 4つの支援：AI研修・教育／オーダーメイド開発／業務改善・経営支援／伴走サポート。モノライン図形と短い説明を併置。
3. 支援の考え方：「道具より先に、仕事を見ます。」と大きな画像面。
4. 青緑CTAバンドとフッター。

### 2. サービス詳細（service-detail）

完成例はAI実践研修です。ヒーローの後に「こんな時に」（困りごと3件）、「進め方」（聞く→試す→整える）、「提供内容・料金：要確認」を置きます。料金、対象人数、回数は確定前に創作しません。

### 3. 導入事例・プロフィール（works-profile）

事例は大きな編集的写真面と小事例の組み合わせです。社名・掲載許諾・成果数値は要確認。プロフィールは代表の言葉を主役にし、プロフィール本人写真のみ顔が判別できる写真を使用可能とします。代表者名・経歴・資格は要確認です。

### 4. FAQ・お問い合わせ（faq-contact）

FAQは「Q + 質問 + 開閉記号」の罫線アコーディオンです。タップ行は44px以上とし、実装時はEnter/Spaceと`aria-expanded`を同期します。フォームは一列構成で、送信中の二重送信防止、項目近くの入力エラー、成功時のthank-youページ遷移を実装します。エラーは例として `CONTACT_EMAIL_INVALID` のように原因と識別子を表示します。

### 5. 法定・状態ページ（legal-status）

プライバシーポリシーと特定商取引法表記は読みやすい長文レイアウトにします。事業者情報、所在地、料金、返金条件、連絡先などの未確定情報は必ず要確認として保持します。thank-youと404は、状態説明に加えて「トップへ戻る」「無料相談」の次の導線を明示します。

## 実装時の注意

- 写真は一般写真では顔が判別できない手元、後ろ姿、斜め後方、ぼかしを用い、自然光と白〜青緑の空気感に揃えます。
- SVGアイコンは塗りアイコンや絵文字を混在させず、モノラインとラベルの組み合わせにします。
- 現在ページは下線と`aria-current="page"`、キーボードフォーカスは可視化します。
- CTAの失敗は曖昧な文言にせず、代替の無料相談導線を示します。
- フォーム等でエラーが表示されたら、表示文章をそのまま連絡してもらえる案内を掲載します。
- 料金、実績、法定表記、プロフィールの要確認箇所は公開文言に置き換えません。
