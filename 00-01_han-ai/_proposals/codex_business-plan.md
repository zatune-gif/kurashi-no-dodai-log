# ざつね屋「半AIプロジェクト」事業計画書

## 1. エグゼクティブサマリー

ざつね屋は、広島県府中市を拠点に、中小企業・地域事業者の仕事を生成AIで小さく改善し、最終的に自社で改善を続けられる状態をつくる事業を行う。生成AIの導入や操作研修そのものではなく、**業務整理、人材育成、小規模な実装、効果測定、横展開、内製化を一つにつなぐ「地域企業の小さな業務変革室」**として位置づける。

初期顧客は、生成AI活用を任された従業員数十名規模の地域企業の管理職・実務責任者とする。商工会議所・業界団体・既存ネットワークを入口に、AI実務研修から接点を作り、3か月の「AI業務改善実践室」、6か月の「社内推進者育成プログラム」へつなぐ。

現在はP2・確認フェーズで、営業活動はこれからである。実案件は1件を蓄積中だが、研修コース①〜⑤の教材一式、自社開発ツール18件、パソコン講師・地域団体運営・ウェブ制作・管理職・社内デジタル化推進・専門学校担任の経験がある。研修体系は全6コースだが、完成済み教材は①〜⑤であり、⑥は別枠の専門コースとして扱う。実績数を誇張せず、動くツール、完成済み教材、検証記録、顧客の小さな成果を信頼の根拠にする。

計画の基準は手取り月30万円の安定であり、必要月商35〜40万円を目安とする。単発研修だけに依存せず、3〜6か月商品を2〜3社並行し、研修を新規接点として組み合わせる収益構造を目指す。

## 3. 事業の目的

### 顧客に対する目的

地域企業が生成AIを導入すること自体ではなく、現場の仕事を一つずつ改善し、その変化を測り、社内の人が次の改善を進められる状態をつくる。

### ざつね屋にとっての目的

半AIプロジェクトで手取り月30万円を安定させ、生活基盤を守りながら、将来の半農事業や地域での新しい実践へ投資できる収益と地域接点を作る。

### 社会的な目的

専任のデジタル化担当者や大規模な開発予算を持ちにくい地域企業に、業務整理、教育、小さな実装、定着を分断せず提供する。外部サービスへの依存を増やすのではなく、地域企業の内部に改善する力を残す。

## 4. 解決する課題

### 顧客が抱える課題

- 経営者からAI活用を求められたが、担当者が何から始めるべきか分からない。
- 無料情報や個人利用で試しているが、利用が一部の社員に偏っている。
- 一般的な研修を受けても、自社業務での実践につながらない。
- 現場から「仕事が増える」「今のままで困っていない」と反発される。
- 情報管理、確認方法、利用ルールを決められない。
- 導入後の効果を測れず、次の投資判断ができない。
- 成功した使い方を手順や事例に残せず、他部署へ広がらない。
- 専任担当者を採用するほどの予算はないが、片手間の担当者だけでは進まない。

### 既存の代替手段の不足

| 代替手段 | 利点 | 不足しやすい点 |
|---|---|---|
| 無料動画・記事 | 安価で情報量が多い | 自社業務の選定、現場への適用、継続支援がない |
| 一般的なAI研修 | 共通知識を短時間で得られる | 受講後の実践、効果測定、横展開まで届きにくい |
| システム開発会社 | 大きな仕組みを実装できる | 業務整理前の小さな試行や社員教育には過大になりやすい |
| 経営コンサルタント | 経営課題を整理できる | 小さなツールやプロンプトをその場で実装できるとは限らない |
| 社内担当者の独学 | 現場を理解している | 時間、知識、権限が不足し、孤立しやすい |

## 5. 事業コンセプトと提供価値

### コンセプト

> **AIを入れることより、仕事がよくなることから。**

ざつね屋は、地域企業の仕事を生成AIで小さく改善し、最後は自分たちで続けられる形をつくる。

### 提供価値

1. **目的から始める：** ツールありきではなく、解決したい業務課題を決める。
2. **現場と小さく試す：** 最初から全員へ広げず、推進役1〜3人と一業務で試す。
3. **効果を確かめる：** 時間、品質、迷い、利用状況を、数値と利用者の声で見る。
4. **再現できる形にする：** 入力様式、作業手順、確認基準、利用ルール、例外時の対応、社内事例を一つの業務運用パッケージとして残す。
5. **自社へ力を残す：** 推進役が他の社員へ教え、次の業務を選べる状態を目指す。

### 顧客の成長段階

| 段階 | 顧客の状態 | 主な支援 |
|---|---|---|
| 知る | 生成AIの可能性と注意点を知る | 理解度テスト、基礎研修 |
| わかる | 自社の目的と対象業務を説明できる | 準備度診断、業務棚卸し |
| できる | 一業務で手順に沿って使える | 個別業務設計、3か月実践室 |
| 教える | 推進役が同僚へ説明できる | ルール運用定着研修、社内共有会 |
| 内製化 | 効果を測り、次の業務へ広げられる | 6か月推進者育成、継続伴走 |

## 6. ターゲット市場

### 主ターゲット

従業員数十名規模の中小企業・地域事業者で、生成AI活用を任された管理職・実務責任者。生成AIへの関心があり、社内で小さく試す権限または推進役を持つ、初期採用層を最初に狙う。

### 副ターゲット

1. **商工会議所・業界団体・研修企画担当者：** 会員企業や社員向けに、受講後の実践につながる研修を求める層。
2. **文書・調整業務が多い地域企業：** 業種を限定せず、見積もり、報告、問い合わせ対応、会議記録、引き継ぎなどの反復業務があり、改善責任者と測定可能な対象業務を持つ企業。

### 業種より先に見る「適合条件」

現段階では、特定業界を最適市場と断定できる顧客データがない。最初は業種ではなく、次の条件で案件を選ぶ。

1. 経営者または管理職が、解決したい業務課題を持っている。
2. 同じ文書・判断・確認作業が週次または月次で繰り返されている。
3. 現行の作業時間、件数、差し戻し、迷いなどを測れる。
4. 推進役1〜3人が試行に参加できる。
5. 機密情報を除いたデータ、または安全な検証用データを用意できる。
6. 3か月以内に試行と判断ができる。

中小企業基盤整備機構の2026年調査では、中小企業のAI導入率は20.4%、検討中を合わせると39.0%であり、目的は「業務効率化・作業時間短縮」が8割超で最も多い。また、活用事例への情報需要が高い。したがって、業界名より「時間を測れる反復業務」と「事例を必要とする推進担当者」を入口にする方が、現時点の根拠に合う。([中小企業基盤整備機構「中小企業のAI等の利活用に係る実態調査」](https://www.smrj.go.jp/research_case/questionnaire/fbrion0000002pjw-att/202603_AI_point.pdf))

### 農業分野の扱い

**結論：農業を現時点の優先ターゲットから外し、「地域接点を生かした探索テーマ」に下げる。**

農業分野に課題がある根拠はある。農林水産省は、担い手不足、導入コスト、技術を扱える人材の不足、従来の生産方式のままでは導入効果が出にくいことを課題としている。また、農業支援サービスの利用希望者も増えている。([農林水産省「スマート農業技術の活用と今後の展望」](https://www.maff.go.jp/j/wpaper/w_maff/r6/r6_h/trend/part1/chap0/c0_1_03.html))

ただし、これらは主に生産現場やスマート農業機械に関する根拠であり、ざつね屋が想定した「農業の事務仕事に生成AIを使うサービス」への支払意向、頻度、削減可能時間を裏づけない。したがって「農業は競合が少なそう」「移住先と近い」だけで最適業界と判断しない。

農業を事業ターゲットへ上げる条件は、農業法人・農業協同組合・集落営農への10件程度の聞き取りで、同じ事務課題が5件以上に現れ、月当たりの負担、現在の代替手段、決裁者、予算を確認できることである。それまでは価格付き商品を置かず、無償の聞き取りと有償化前の小規模検証に限定する。

### 初期の対象外

- 大規模な基幹システム開発を求める企業
- 生成AIの導入だけを目的とし、現場検証や効果測定を行わない案件
- 法務・医療など、高度な専門判断をAIへ代替させる案件
- 業務範囲を決めず、無制限の制作・相談対応を求める案件
- 短期間での売上増加や人員削減を保証するよう求める案件

### 業務発見セッションは、まだ販売しない

90分・30,000円という設定には、時間、成果物、顧客の支払意向を裏づける実績がない。したがって名称・時間・価格を確定商品として扱わない。まず3〜5件の実案件またはモニターで、次のテンプレートを使って再現性を検証する。

1. **目的確認：** 経営上または現場上、何を良くしたいか。
2. **業務列挙：** 頻度が高い、時間がかかる、差し戻しが多い、属人化している業務を出す。
3. **一業務の分解：** 開始条件、入力、判断、作業、確認、出力、例外を並べる。
4. **現状測定：** 1件当たり時間、月間件数、ミス、待ち時間、関与人数を確認する。
5. **AI適合判定：** 文章・画像・整理・生成が中心か、正解精度、機密性、人の確認可能性を評価する。
6. **試行候補の順位づけ：** 効果の大きさではなく、「小さく安全に試せ、結果を測れるか」で選ぶ。
7. **次の判断：** 自社で試す、研修が先、3か月実践室で試す、AIを使わない、のいずれかを選ぶ。

テンプレートの成果物は「業務候補一覧」「対象業務の流れ」「現状値」「適合判定」「次の行動」の5点とする。所要時間を3〜5件で測った後、60分・90分・複数回のどれが妥当か決める。顧客が成果物に対価を払う意向を確認して初めて価格を設定する。

### 「専用プロンプト」は商品ではなく部品

プロンプトは容易に複製・変更でき、単体では業務に定着する価値を説明しにくい。プロンプトを渡して終わるサービスは、ざつね屋の強みである業務整理、教育、実装、伴走も生かさない。したがって「専用プロンプト制作」を主商品名や主成果物にしない。

納品単位は**業務運用パッケージ**とする。

- 対象業務と利用目的
- 使用者、開始条件、入力様式
- AIへの指示または小さなツール
- 良い出力例・悪い出力例
- 人が確認する項目と最終責任者
- 機密情報・個人情報の扱い
- 例外時の相談・停止手順
- 利用記録と効果測定方法
- 操作説明と試行後の修正

顧客は文章としてのプロンプトではなく、「社員が安全に繰り返せ、結果を確認できる業務の型」に対価を払う。単純なプロンプトだけで解決する案件は、研修内で自作方法を教えるか、低価格の教材として扱い、50,000円以上の個別業務設計にはしない。

## 15. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 営業実績が少ない | 契約判断が進まない | 完成済み教材、開発物18件、実案件の検証過程、低額入口で信頼を作る |
| 生成AIへの期待が過大 | 成果への不満 | AIが適さない判断も行い、基準値と到達点を契約前に決める |
| オーダーメイド範囲の膨張 | 採算悪化、納期遅延 | 対象業務・利用者・修正回数を限定し、追加は別見積もり |
| 一人事業による稼働限界 | 品質低下、機会損失 | 継続案件は初期3社まで。ひな型化し、開始時期を調整する |
| 顧客情報の取り扱い | 信用・法的リスク | 入力禁止情報、使用サービス、保存、削除、確認者を事前に決める |
| 特定AIサービスへの依存 | 仕様・価格変更 | 顧客の業務と成果物を中心にし、代替可能な手順を残す |
| 地域市場が小さい | 案件不足 | 団体経由、オンライン対応、紹介で商圏を広げる。根拠のない業界特化は行わない |
| 安価な単発相談だけが増える | 売上不安定 | 診断後に3つの選択肢を示し、3〜6か月商品を事業の中心にする |
| 助成制度への誤解 | 信頼低下 | 対象となり得る旨と、要件確認が必要であることを明記する |
| 内製化で契約が終了する | 継続売上減少 | 卒業を成果として事例化し、必要な顧客だけ外部担当・四半期点検へ移行する |

## 16. 事業上の判断基準

新しい案件・商品は、次の5項目で判断する。

1. 顧客の業務課題が具体的か。
2. 3か月以内に小さく試せるか。
3. 効果または判断材料を残せるか。
4. 顧客社内の推進役がいるか。
5. ざつね屋の「教える・整える・作る・続ける」が生きるか。

4項目以上を満たす案件を優先する。大きな開発だけ、講演だけ、無制限相談など、強みが分断される案件は、範囲を組み替えるか見送る。
